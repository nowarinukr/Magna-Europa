# Перший запуск тестової копії у Windows

Ціль — HOI4 1.19.4. Це експериментальний порт; успішний запуск у грі ще не підтверджено. Потрібна нова кампанія. Для цих кроків Python та завантаження ZIP із чату не потрібні.

## Отримати файли через GitHub Desktop

1. Вибери `Magna-Europa` у `Current repository`.
2. Натисни `Fetch origin`. Якщо кнопка вже показує `Pull origin`, спочатку отримай зміни поточної гілки.
3. Натисни `Current branch` і вибери `codex/hoi4-1.19.4-test` (може бути показана з префіксом `origin/`). Якщо є поле пошуку, введи назву гілки туди. Вибирати створення нової гілки не потрібно.
4. Натисни `Pull origin`, якщо після перемикання така кнопка з'явиться.
5. Відкрий `Repository → Show in Explorer`. У корені мають бути цей файл і папка `local-test`.

Якщо GitHub Desktop повідомить про незбережені зміни під час перемикання, збережи їх через запропоноване програмою перенесення або stash; не вибирай їх відкидання. Можна надіслати скриншот повідомлення для уточнення.

## Підготувати окрему локальну копію

1. Закрий HOI4 і лаунчер.
2. Відкрий `Документи\Paradox Interactive\Hearts of Iron IV\mod`. Папка «Документи» може розташовуватися в OneDrive. Якщо папки `mod` немає — створи її.
3. Усередині `mod` створи папку `great_bruh_1194_test`. Якщо така папка вже є, спочатку збережи її як окрему резервну копію: старі файли не повинні змішуватися з цим тестом.
4. З отриманого репозиторію скопіюй у `great_bruh_1194_test` папки `common`, `events`, `gfx`, `history`, `interface`, `localisation`, `map`, `music`, `tutorial` і файли `bruh.png`, `thumbnail.png`.
5. Із папки репозиторію `local-test` скопіюй **`descriptor.mod` усередину `great_bruh_1194_test`**, а **`great_bruh_1194_test.mod` — безпосередньо в `mod`, поруч із тестовою папкою**.

Має вийти так:

```text
Hearts of Iron IV
└── mod
    ├── great_bruh_1194_test.mod
    └── great_bruh_1194_test
        ├── descriptor.mod
        ├── common
        ├── events
        ├── gfx
        ├── history
        ├── interface
        ├── localisation
        ├── map
        ├── music
        ├── tutorial
        ├── bruh.png
        └── thumbnail.png
```

Описувачі з `local-test` містять усі потрібні `replace_path`, окрему тестову назву та відносний шлях. Ідентифікатора оригінального Workshop у них немає. Джерельний `descriptor.mod` у корені репозиторію залишається оригінальним і не призначений для цих кроків.

## Запустити та надіслати результат

1. Відкрий лаунчер, знайди **Great Bruh V2 - 1.19.4 TEST** і додай його до окремого набору модів.
2. Для першої перевірки ввімкни лише цей мод, вибери мову **English**.
3. У Steam можна додати `-debug` у **HOI4 → Властивості → Загальні → Параметри запуску**.
4. Запусти гру, спробуй нову кампанію 1911 року. Якщо вона завантажилась, перевір дослідження, виробництво, фокуси та кілька ігрових днів.
5. Закрий гру й одразу збережи **`error.log`** і **`game.log`** із `Документи\Paradox Interactive\Hearts of Iron IV\logs`; наступний запуск може їх перезаписати. Надішли їх у чат разом із переліком увімкнених DLC та описом, до якого етапу дійшла гра.

Чернетку українського перекладу підключаємо після окремої перевірки запуску: дивись `translations/uk/README.md`. Зміна `supported_version` у тестових описувачах указує ціль тесту й не підтверджує сумісність рушія.
