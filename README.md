# Great Bruh V2: адаптація та український переклад

Робоча копія моду Great Bruh V2 у репозиторії Magna-Europa. Ціль адаптації — **Hearts of Iron IV 1.19.4**; у вихідному `descriptor.mod` заявлена версія `1.14.*`. Перенесення ще не завершене, запуск у 1.19.4 не перевірено.

У першому наборі виправлено помилки структури скриптів, локалізації та дублікати стратегічних регіонів. Подробиці, межі перевірок і подальша перевірка у грі: [звіт міграції](docs/migration-1.19.4.md).

Другий етап зіставив Lua-параметри з трьома файлами базової гри, наданими користувачем: [результати порівняння](docs/defines-1.19.4.md). Виправлено невірні шляхи параметрів і неузгоджене перевизначення морського пробиття.

Перший запуск у користувача виявив темну карту та виліт. За журналами прибрано застарілу підміну `gfx/FX/constants.fxh`, яка не містить потрібного шейдерам `MUD_CAM_MIN`; резервна копія збережена в документації. Початкова діагностика: [звіт першого запуску](docs/crash-1.19.4-first-run.md).

Користувач підтвердив видиму карту після цієї зміни; виліт на старті кампанії залишився. Подальше оновлення адаптує формат будівель та відновлює сучасні категорії й переліки типів: [звіт і встановлення оновлення](docs/buildings-enums-1.19.4.md). Чотири застарілі поля витрат ресурсів тимчасово неактивні; економічний баланс потребує подальшої роботи.

Наступний запуск підтвердив усунення повідомлень про будівлі й категорії, але виліт зберігся. Тест без старого вікна виробництва теж не допоміг. Для наступного дослідження додано позначки етапів у журнал; виявлено 251 порожній блок погоди: [стан діагностики](docs/startup-diagnostics.md). Причину вильоту ще не встановлено.

## Перевірка файлів

Потрібен Python 3.10 або новіший; додаткових пакетів немає. З кореня репозиторію:

```sh
python tools/validate_mod.py
python tools/check_buildings.py
python -m unittest discover -s tests -v
```

На системах, де команда називається `python3`, використовуйте її замість `python`. Це статичні перевірки файлів, а не тести рушія HOI4. Lua-параметри, ефекти, тригери, сумісність DLC та ігровий баланс ними не перевіряються.

Окрема перевірка Lua-параметрів за файлами власної встановленої гри:

```sh
python tools/check_defines.py --vanilla-dir "C:/path/to/Hearts of Iron IV/common/defines"
```

Команда читає Lua як дані, не виконує його. Потрібні `00_defines.lua`, `00_graphics.lua`, `01_career_profile.lua`; вони не включені в репозиторій чи тестовий пакет. Валідатор повідомляє невідомі ключі, зміну типів і розмірів таблиць; семантику всіх параметрів він не встановлює.

Порівняння категорій та enum зі своєю грою:

```sh
python tools/check_enums.py --vanilla-categories "C:/path/to/game/common/unit_tags/00_categories.txt" --vanilla-enums "C:/path/to/game/common/script_enums.txt"
```

Це перевірка переліків і посилань категорій, не наявності всіх об'єктів спорядження/технологій у рушії.

## Пакет для локального тесту

Якщо завантаження ZIP із чату не працює, можна отримати файли через GitHub Desktop і підключити тестову копію без Python: [покрокова інструкція для Windows](INSTALL_TEST_WINDOWS.md). Готові локальні описувачі лежать у `local-test`.

```sh
python tools/build_test_package.py --output "C:/path/outside/checkout/Great-Bruh-1.19.4-TEST.zip"
```

Шлях виводу має бути поза репозиторієм, файл ще не повинен існувати. Пакет містить повну окрему копію моду з назвою `Great Bruh V2 - 1.19.4 TEST`, локальний `.mod`, інструкцію та необов'язкову чернетку перекладу. Застарілі дублікати карти вже вилучені. Тестові описувачі зберігають усі `replace_path`, але не містять оригінального `remote_file_id`; джерельний `descriptor.mod` не змінюється. У тестовому пакеті `supported_version="1.19.*"` позначає ціль тестування, а не підтверджену сумісність.
